Veyra

A free, local-first video editor and 52 video tools that run entirely in the browser.

1.2Kvisits in 3 days

No uploads, no account, no watermark, no export limits. Every frame is decoded and encoded on the user's own device with WebCodecs inside Web Workers, so files never leave the machine.

  • Multitrack editor with drag, trim, roll, slip, split and ripple, built on a frame-exact "flick" timebase so edits never drift.

  • Crash-safe autosave, strict CSP and cross-origin isolation; a "harsh" suite of hostile files (MPEG-TS, WebM subtitles, single-frame clips) that found and fixed real bugs.

Market Data Simulator

An HFT-style market microstructure lab with a real-time web dashboard.

It generates realistic exchange order flow, moves it across threads through a wait-free ring buffer, rebuilds a price-time-priority order book, paper-trades strategies against it live and replays everything through a backtester.

  • Tick-to-trade in about one microsecond: ITCH packet in, book update, signal, risk checks, OUCH order out, on three pinned busy-spin threads.
  • Flat order book with a price-ladder array, intrusive pool and bitmap best-price search: no allocation on the hot path.
  • Nasdaq TotalView-ITCH 5.0 parser that replays real exchange files; MoldUDP64 over UDP with gap detection and re-request recovery.
  • Pre-trade risk gate in the style of SEC 15c3-5, and a backtester that tracks FIFO queue position exactly, with fees, Sharpe, Sortino and drawdown.

IngredientTrace

AI-agent allergen change control for restaurants.

When a supplier changes a product, one missed allergen can reach a customer. An AI agent reads the new label and proposes the change; a person approves it; the system traces exactly which dishes and menus it affects.

  • Custom MCP server with six tools that read supplier label images, propose ingredient changes and trace impact across nested recipes and published menus.
  • Human-in-the-loop by design: the agent can only propose, never approve. Schema-validated tool calls, access revocation and credential rotation.
  • Impact is calculated by deterministic recursive graph traversal, not by asking an LLM, so the allergen answer is always exact.
  • Normalised PostgreSQL with deduplication, canonical EU-14 allergen mapping, versioned records, isolated pending changes and audit trails.

distcache

A Redis-compatible distributed key-value cache, written from scratch in Go.

It speaks the real Redis wire protocol, so the stock redis-cli and any Redis client library work against it. Any node accepts any key and forwards it to the owner.

  • Consistent hashing with 150 virtual nodes per server; adding a fourth node moves 22.6% of keys, close to the ideal 25%, all to the new node.
  • Each node's cache is owned by one goroutine (actor pattern), so connections talk to it over channels with no locks around the data.
  • O(1) LRU eviction from a hash map and a hand-written doubly linked list; TTL expiry both lazily on read and by a background sampler, like Redis.
  • Pipelining, connection limits, idle timeouts and graceful shutdown; a Docker Compose cluster and a load generator that reports p50, p95 and p99.
